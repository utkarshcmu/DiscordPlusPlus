DiscordPlusPlus

Leaderboard for your Discord server

Add to your Discord server

Usage

Give Points (++)

++ adds 1 point.

@username++
  • No self-points
  • Each mention counts

Remove Points (--)

-- subtracts 1.

@username--
  • Can go negative
  • No self-removal

Commands

Leaderboard

Type leaderboard to see rankings.

@PlusPlus leaderboard

Help

Type help for instructions.

@PlusPlus help
